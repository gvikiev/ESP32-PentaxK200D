# Pentax K200D Remote Dashboard — Web UI Specification & Design Language

## 1. Общий дизайн-язык и стиль

- **Концепция:** Тёмная тема по умолчанию для комфортной съёмки в тёмное время суток и астрофотографии. Минималистичный дизайн с крупными сенсорными элементами управления (touch-friendly, выровненными под пальцы).
- **Цветовая палитра:**
  - **Основной фон:** `#121212` (глубокий тёмно-серый)
  - **Карточки и панели:** `#1E1E1E`
  - **Границы и разделители:** `#2C2C2C`
  - **Акцентные цвета:** `#E85D2A` (фирменный оранжевый Pentax) и `#00C2A8` (бирюзовый для активных статусов)
  - **Текст:** `#E0E0E0` (основной), `#9E9E9E` (вторичный/подписи)
  - **Индикаторы состояний параметров:**
    - `available` (доступно для чтения и записи) — Бирюзовый `#00C2A8`
    - `write-only` (запись без подтверждения из статуса) — Янтарный `#F5A623`
    - `experimental` (экспериментальные параметры) — Фиолетовый `#9B59B6`
    - `unknown` / `unavailable` — Серый / Приглушённый красный `#7A3B3B`
- **Типографика:** Системные шрифты Inter / Roboto / San Francisco. Заголовки карточек: 18–20 px, значения параметров: 16 px, сервисные подписи: 12 px.
- **Сетка и компоновка:** 
  - Mobile (смартфоны): Одна колонка.
  - Tablet / Desktop: Двухколоночный макет.
  - Карточки с закруглением 12 px и внутренними отступами 12–16 px.

## 2. Экраны и компоновка интерфейса

### 2.1. Экран 1 — Пульт управления съёмкой (`MSC_PENTAX_READY`)

```
┌─────────────────────────────────────────────┐
│  ● Pentax K200D         FW 1.00   [SR ●]    │  ← Шапка: модель, прошивка, статус SR
│  Wi-Fi: 3 clients        [Диагностика]      │
├─────────────────────────────────────────────┤
│  ОБЪЕКТИВ                                   │
│  ┌───────────────┬───────────────┐          │
│  │ 50 mm         │ F3.5 – F22    │          │  ← Фокусное расстояние и диапазон F-чисел
│  └───────────────┴───────────────┘          │
├─────────────────────────────────────────────┤
│  ЭКСПОЗИЦИЯ                                 │
│  1/250   F5.6   ISO 400   +0.3 EV           │  ← Крупные значения (тап открывает слайдер)
│  [────────●────────]  выдержка              │
│  [──────●──────────]  диафрагма              │
│  [────●────────────]  ISO                   │
│  [──────●──────────]  EC                    │
├─────────────────────────────────────────────┤
│  ФАЙЛ                                       │
│  [JPEG] [RAW] [RAW+]     10M ★★★            │  ← Сегментированный переключатель
│  Размер: [10M] [6M] [2M]   Звёзды: [★][★★][★★★] │
├─────────────────────────────────────────────┤
│  ИЗОБРАЖЕНИЕ (experimental)                 │
│  Tone: [Bright][Natural][Portrait][Landscape][Vibrant][Mono] │
│  Sat [─●─]  Sharp [─●─]  Contrast [─●─]  Hue [─●─] │
├─────────────────────────────────────────────┤
│  ФОКУС И ЗАМЕР                              │
│  AF: [AF.S] [AF.C]    Зона: [Auto][Select][Spot] │
│  Точки AF:  ○ ○ ● ○ ○ ○ ○ ○ ○ ○ ○           │  ← Сетка 11 точек (активная подсвечена)
│  Замер: [Multi][Center][Spot] (write-only)  │
│  Drive: [Single][Cont.Hi][Cont.Lo][Timer]  │
├─────────────────────────────────────────────┤
│  БУФЕР (2 занято / 10)                      │
│  [кадр 1: JPEG 3.9 МБ] [Просмотр][Скачать]  │
│  [кадр 2: PEF 10.2 МБ] [Просмотр][Скачать]  │
│  ⚠ Непереданный кадр: JPEG 3.9 МБ [Докачать]│  ← Отслеживание buffer.pending
├─────────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────────────┐ │
│  │   AF (полу-) │  │   СПУСК (большая)    │ │  ← Главные управляющие кнопки
│  └──────────────┘  └──────────────────────┘ │
│  [Серия] [Интервалометр] [Bulb] [Таймер]    │
└─────────────────────────────────────────────┘
```

#### Поведение элементов управления:
1. **Кнопка «Спуск»:** Переходит в неактивное состояние (серая закраска) при выполнении съемки (`busy`) или при заполнении всех 10 слотов RAM-буфера камеры с выводом предупреждения *«Буфер заполнен»*.
2. **Параметры `write-only` (WB, Режим замера, Вспышка):** Отображают последнее отправленное пользователем значение с бейджем янтарного цвета *«Записано (без подтверждения)»*.
3. **Индикатор Shake Reduction (SR):** Выводит текущий статус системы оптической стабилизации, считываемый из 408-байтового буфера состояния камеры.

### 2.2. Экран 2 — Галерея SD-карты (При доступности `sd.browse`)

```
┌─────────────────────────────────────────────┐
│  ← Назад к пульту     Карта SD     [Обновить]│
├─────────────────────────────────────────────┤
│  Фильтр: [Всё] [JPEG] [RAW]   Сортировка: [Дата ▼] │
├─────────────────────────────────────────────┤
│  ┌─────┐ ┌─────┐ ┌─────┐                    │
│  │ IMG │ │ IMG │ │ IMG │  ← Ленивая загрузка миниатюр (EXIF)
│  │ 001 │ │ 002 │ │ 003 │                    │
│  └─────┘ └─────┘ └─────┘                    │
│  ┌─────┐ ┌─────┐ ┌─────┐                    │
│  │ IMG │ │ IMG │ │ IMG │                    │
│  │ 004 │ │ 005 │ │ 006 │                    │
│  └─────┘ └─────┘ └─────┘                    │
│  ...                                        │
├─────────────────────────────────────────────┤
│  Выбрано: 2 файла   [Скачать]  [Удалить ✕]  │  ← Безопасный режим (Read-Only)
└─────────────────────────────────────────────┘
```

#### Поведение элемента Галереи:
- Фильтрация по типам файлов (JPEG / RAW / All).
- Отображение оригинальных имён файлов: `IMGPxxxx.JPG` (sRGB) или `_IGPxxxx.JPG` (AdobeRGB).
- Параллельная загрузка миниатюр ограничена 1–2 потоками для сохранения стабильности USB-соединения.
